Política de privacidade

Última atualização: 6 de outubro de 2026

O HawkClaw Earnings Agent é uma ferramenta de uso interno da HawkClaw. Esta página descreve que dados da conta Google a ferramenta usa e para quê.

Que dados são usados

  • Google Calendar (só leitura): o título e a data dos eventos do calendário de resultados, para saber quando cada empresa divulga resultados. A ferramenta nunca cria, altera nem apaga eventos.
  • Google Drive (só ficheiros da própria ferramenta): a ferramenta guarda os documentos públicos que recolhe numa pasta própria. Não tem acesso a outros ficheiros do Drive.
  • Gmail (só envio): a ferramenta envia emails de alerta para a equipa. Não lê, não guarda nem apaga emails.

Como são usados e guardados

Os dados são usados apenas para o funcionamento da ferramenta. Não são vendidos, partilhados com terceiros nem usados para publicidade. As credenciais de acesso são guardadas de forma cifrada e acessíveis apenas aos responsáveis pela ferramenta. Os documentos recolhidos são informação pública divulgada pelas próprias empresas.

Uso de dados das APIs Google

O uso e a transferência de informação recebida das APIs Google cumprem a Google API Services User Data Policy, incluindo os requisitos de uso limitado (Limited Use).

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Privacy policy (English)

HawkClaw Earnings Agent is an internal HawkClaw tool. It reads event titles and dates from the results calendar (read-only), stores the public documents it collects in its own Google Drive folder (it can only access files it created), and sends alert emails to the team (send-only; it never reads email). Data is used only to operate the tool, is never sold or shared with third parties, and complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions. Contact: hawkclawagent@gmail.com.
